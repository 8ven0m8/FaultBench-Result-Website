Fault injection

Byzantine / adversarial agents

Swap an agent's policy for an adversarial one

Injection definition

Byzantine / adversarial injection models rogue, hacked, or severely corrupted agents by swapping a cooperative agent's policy for an adversarial one at runtime (onset between steps 40-60). The compromised node actively broadcasts misleading coordination messages or takes counter-productive physical actions (such as intentionally mis-sorting materials or triggering unnecessary presses), testing whether the multi-agent system can isolate malicious nodes and preserve safety guarantees.

Duration modes

  • Permanent: the fault persists for the relevant evaluation.
  • Transient: the fault is introduced for a bounded interval.

Recovery mechanisms

  • Rule-based reconfiguration
  • Fault-tolerant-trained MARL
  • Hierarchical supervisor-agent
  • LLM-agent replanning
