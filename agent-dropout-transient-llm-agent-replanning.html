LLM-agent replanning

Transient agent dropout evaluation

Fault: Agent dropout
Duration: Transient
Recovery mechanism: LLM-agent replanning

Experiment definition

The experiment evaluates LLM-agent replanning under a transient agent dropout injection. Fault onset is randomized around environment steps 40-60 according to the implementation plan.

Expected evaluation record

MetricRecorded value
Time-to-recovery72.5 steps (mean, n=4 recovered non-null of 24)
Degradation-area13.33 (corrected; mean, n=24)
False-recovery rate0.799 (mean, n=24 runs)
Safety-violation count50.2 (mean raw count: catastrophic+severe+near-miss, n=24)

Values are means across every target × duration-fixed combination shown on this page (see graphs below), 8 seeds each. See the Results page for confidence intervals and the cross-mechanism comparison.
